# Personal Website – Lili Fidini Rizqi

## 📌 Tentang Projek

**Personal Website Lili Fidini Rizqi** adalah website pribadi yang dibuat sebagai bagian dari proses pembelajaran dan latihan dalam mengembangkan kemampuan dasar **Web Development**. Website ini dibangun menggunakan **HTML dasar tanpa CSS**, sehingga berfokus pada pemahaman struktur halaman web, penggunaan elemen HTML, navigasi antarhalaman, tabel, formulir, gambar, serta penyusunan informasi secara terstruktur.

Website ini juga menjadi media sederhana untuk memperkenalkan profil, minat, pengalaman projek, serta menyediakan halaman kontak yang dapat digunakan untuk berkomunikasi.

## 👩‍💻 Tentang Saya

Saya adalah **Lili Fidini Rizqi**, mahasiswa Program Studi **Pendidikan Sistem dan Teknologi Informasi (PSTI)** di Universitas Pendidikan Indonesia. Saat ini saya sedang mempelajari berbagai dasar teknologi informasi, khususnya dalam bidang **Web Development**.

Saya memiliki ketertarikan untuk terus mempelajari pembuatan website dan teknologi informasi. Salah satu target saya adalah dapat menghasilkan website yang bermanfaat dan mudah digunakan.

## 🌐 Struktur Website

Website ini terdiri dari beberapa halaman utama:

* **Home** – Halaman utama yang berisi perkenalan singkat dan informasi mengenai hal-hal yang sedang dipelajari.
* **About** – Berisi profil, data diri, hobi, dan riwayat pendidikan.
* **Project** – Menampilkan projek-projek yang pernah atau sedang dikerjakan.
* **Contact** – Menyediakan informasi kontak dan formulir untuk mengirim pesan.

Seluruh halaman saling terhubung melalui navigasi utama sehingga pengguna dapat berpindah dari satu halaman ke halaman lainnya.

## 🚀 Projek yang Ditampilkan

### 1. Website Biodata

Website sederhana yang digunakan untuk menampilkan informasi biodata pribadi. Projek ini dibuat menggunakan **HTML** dan menjadi salah satu latihan dasar dalam memahami pembuatan halaman web.

### 2. Zamzam Hidden Spot

**Zamzam Hidden Spot** merupakan sebuah sistem pada bidang bisnis **Tourism**. Dalam projek ini, saya berperan sebagai **koordinator Tim Difine**.

Melalui projek ini, saya mempelajari penggunaan **Figma** serta konsep *unique value* dalam sebuah sistem. Projek masih berada dalam bentuk **UI/UX** dan masih dapat dikembangkan lebih lanjut.

### 3. Game Kreswara

**Kreswara** merupakan game edukasi yang mengangkat tema **pemrograman dan budaya**. Dalam projek ini, saya bertugas sebagai pengawas pelaksanaan pembuatan game.

Game ini dikembangkan menggunakan **Ren'Py** dan **GitHub**, sehingga memberikan pengalaman dalam proses pengembangan projek berbasis game serta kerja tim.

### 4. Pangan Teknologi

**Pangan Teknologi** merupakan sistem yang bergerak pada bidang **bisnis dan agraris**. Projek ini dibuat untuk mengikuti perlombaan **Business Plan** pada event *Edutalk Fair Competition Nasional Essay and Business Plan* di Universitas Diponegoro, Semarang.

Dalam projek ini, saya tergabung dalam **Tim Plenger-Tech** dan mengambil bagian pada bidang operasional. Sistem masih berbentuk **UI/UX**, dengan alur bisnis yang telah dirancang melalui *business plan*. Projek ini juga memberikan pengalaman pertama bagi tim dalam mengikuti perlombaan dan berhasil meraih **Bronze Medal**.
